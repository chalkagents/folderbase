# v0.2.0 initialization approval binding verification

This release candidate was developed at the public Core and CLI seams with
red-green-refactor.

## RED evidence

The fixed test-only patch at
`docs/verification/fixtures/v0.2.0-initialization-plan-digest-red.patch`
calls `InitializationPlan::plan_digest()` against the immutable `v0.1.0`
baseline before that public contract existed. It is reproducible without
modifying the baseline:

```sh
git worktree add --detach /tmp/folderbase-v020-red v0.1.0
git -C /tmp/folderbase-v020-red apply \
  "$PWD/docs/verification/fixtures/v0.2.0-initialization-plan-digest-red.patch"
cargo test --manifest-path /tmp/folderbase-v020-red/Cargo.toml \
  -p folderbase-core --test initialization_plan_digest_red
```

The command fails at the new public seam:

```text
error[E0599]: no method named `plan_digest` found for struct `InitializationPlan`
```

The CLI contract tests were then added before the flag and error mapping. The
first build failed at the newly introduced public error seam:

```text
cargo test -p folderbase-cli --test cli init_
error[E0004]: non-exhaustive patterns:
FolderbaseError::InvalidInitializationPlanDigest and
FolderbaseError::InitializationPlanChanged were not covered
```

## GREEN evidence

The focused executable specifications cover:

- stable repeated dry-runs despite different generated IDs and timestamps
- exact request, template package, typed-answer, protocol-write, path/kind
  inventory, and nested-boundary commitments
- one canonical reconstructable-tree policy with explicit Git metadata
- bounded capability traversal and metadata-only sparse 10 GB file handling
- bounded single-directory retention and nested-boundary probe work
- cross-process same-path, same-shape physical root replacement refusal
- outside-root symlink-swap refusal without reading or changing outside bytes
- stale, wrong, and malformed digest refusal before protocol writes
- exact single-plan apply with the applied digest returned
- backwards-compatible direct initialization without an expected digest
