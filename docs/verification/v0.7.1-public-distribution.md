## Independent clean-install audit

The audit used public registries and release assets, not repository build
output:

```sh
npx --yes @folderbase/cli@0.7.1 --version
npm install @folderbase/cli@0.7.1 @folderbase/sdk@0.2.0
cargo install folderbase-cli --version 0.7.1 --locked --root "$TEMP_ROOT"
brew fetch chalkagents/tap/folderbase
gh release download v0.7.1 --repo chalkagents/folderbase
```

The npm launcher resolved and executed `folderbase 0.7.1`. A clean consumer
loaded `@folderbase/sdk@0.2.0`, supervised the public CLI, and returned
`folderbase-compatibility-contract-v1` at contract version `1.0.0`. Cargo
compiled and installed `folderbase-cli 0.7.1` with its exact locked
`folderbase-core 0.7.1` dependency.

Homebrew resolved and fetched Formula 0.7.1. The fetched Apple ARM artifact
matched the formula checksum and returned both `folderbase 0.7.1` and
Compatibility Contract `1.0.0`. This auditing Mac could not execute Homebrew's
final copy step because its host Xcode Command Line Tools require an OS-level
update; Homebrew rejected the host before entering the formula install method.
No system developer-tool change was made as part of release recovery.

The tag workflow
[run 31107294699](https://github.com/chalkagents/folderbase/actions/runs/31107294699)
built all native targets, published the exact-tag crates, GitHub assets, and npm
CLI, then stopped at the SDK's first 0.2.0 publication authorization. The exact
tag SDK and Homebrew formula were subsequently published through the same
sealed package and formula scripts. A failed-job rerun remained unassigned
after the account's GitHub-hosted Actions allowance was exhausted, so the
public checks above were executed locally and recorded explicitly rather than
reported as a successful workflow rerun.

## Superseded 0.7.0 publication

The 0.7.0 crates remain a historical incomplete publication. They were built
from a byte-identical pre-squash tree whose embedded Cargo VCS commit differs
from the canonical `v0.7.0` tag. They are not the release identity for this
capability. Use 0.7.1 on every channel.

## Deliberate nonclaims

This record proves public Core distribution, the stable compatibility surface,
and the exact root-reconstruction capability. It does not make experimental
capabilities stable, deploy Folderbase Cloud, synchronize an existing
non-empty root, prove App distribution, or provide hosted Cloud Agent
execution.
