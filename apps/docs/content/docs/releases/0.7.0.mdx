---
title: Folderbase Core 0.7.0 (superseded)
description: Historical record of the incomplete crate-only 0.7.0 publication.
---

Do not install or integrate Core 0.7.0. Its release workflow stopped before
GitHub binaries, npm, the TypeScript SDK, Homebrew, or public multi-channel
verification were published.

Only the two crates.io packages were uploaded during recovery. They came from
a byte-identical pre-squash source tree, but Cargo embedded that commit identity
in `.cargo_vcs_info.json`; therefore their immutable checksums did not match
the canonical `v0.7.0` tag packages. Crates.io does not allow overwriting a
published version.

The tag and this page remain as an audit record. Core 0.7.1 supersedes 0.7.0
with the same product behavior, packaged and published from one canonical tag.
Use the [Core 0.7.1 release](/docs/releases/0.7.1).
